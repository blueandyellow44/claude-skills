# Voice deferral for morning-agenda

The morning-agenda briefing is a status snapshot. It is NOT prose under the owner's name. It is not an email, post, message, or letter.

**The vault's writing-voice rules (for example a `Context/voice-profile/` folder) do not apply to this skill's output.**

What that means in practice:

- Use plain technical language: lists, headers, source citations.
- No marketing copy, no announcer lines, no figurative language.
- No greeting. No closing line. The briefing is a tool, not a letter.
- Bullets are fine. Any "no bullet-point emails" rule applies to emails. This is a status report.

The one place voice rules DO apply: the single-sentence "Suggested focus" line at the bottom. Keep that line in the owner's register (read `Context/voice-and-writing.md` if the vault has one):

- Plain words.
- Short. One sentence.

If you find yourself writing prose paragraphs anywhere in this briefing, stop. The output should scan in under five seconds. Long prose defeats the point.
