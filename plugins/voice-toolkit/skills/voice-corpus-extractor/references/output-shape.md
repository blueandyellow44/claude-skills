# Output shape

## The corpus file

One markdown file per speaker per kind. A metrics header, then the corpus grouped by source citation. Stage cues stay inline. Layout:

```
# Voice corpus — <Speaker> (<kind>)

> Generated by voice-corpus-extractor. This file COUNTS; it does not JUDGE...
> (narration only) NARRATION CORPUS warning: confirm the narrator IS the speaker...

## Metrics
- turns: ...
- spoken words (stage cues excluded): ...
- mean words/turn: ...
- median words/turn: ...
- short turns (<= 4 words): N (P%)
- arias (>= 60 words): N (P%)
- profanity rate: N hits (P% of spoken words; list size L)
- sources covered: ...

## Corpus

### <source citation>
- <turn, stage cues inline>
- <turn>

### <next source citation>
- <turn>
```

`kind` is `dialogue` or `narration`. For scripts there is only a dialogue file. For prose with `--include-narration` there are two files: `<slug>.md` (dialogue) and `<slug>.narration.md` (narration), each with its own header and stats. They are never concatenated.

## The registry

The skill folder's `registry.md` holds one row per written corpus — a pointer and the stats, never a copy of the lines. Re-running overwrites the project corpus file and appends fresh rows, so the registry is a run log, not a single source of truth. Columns:

```
| timestamp | speaker | kind | format(s) | turns | spoken_words | short% | aria% | sources | corpus_path |
```

`format(s)` shows the per-format file tally for the run, e.g. `prose:1, screenplay:2, stageplay:1`, so a misroute is visible in the log.

## Reading a run for correctness

- **Turn count tracks the roster.** The target's turn count in the corpus should match its dialogue count in `--detect-roster` for the same labels. A large gap means a missed label or a format misroute.
- **Format tally matches the folder.** If you fed three scripts and a novel and the tally says `screenplay:4`, the novel was misread; force `--format prose` on it.
- **Sources covered matches appearances.** Fewer sources than the character appears in means turns were dropped — a label the operator did not confirm, or untagged prose quotes.
- **Prose drop rate is named in the report.** Prose is conservative by design; quotes with no adjacent tag are dropped. The report should say how many, so the builder knows the corpus is a clean subset, not the whole speech.
- **Narration identity is confirmed.** A narration corpus is only trustworthy if the cited first-person narrator IS the target speaker. Confirm before handoff.
- **Empty exits 3.** Zero turns writes nothing and exits 3. An empty corpus is never written.

## Exit codes

- `0` — corpus written.
- `2` — usage or IO error (bad directory, unreadable map, missing required flag).
- `3` — zero turns extracted; nothing written, skipped files listed.
